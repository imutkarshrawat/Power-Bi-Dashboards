# Mobile Sales Dashboard

📊 Power BI Dashboard Project – Mobile Sales Analysis (India)
I recently built an interactive Mobile Sales Dashboard using Power BI, analyzing sales data across India from Oct 2021 to Oct 2024.
This project helped me strengthen my data analysis and visualization skills while working with real-world business insights.

🔹 Key Highlights:
Total Sales reaching 769M+
Analysis of 19K+ quantities sold and 4K+ transactions
Breakdown by city, brand, mobile model, and payment method
Monthly and daily trends to identify peak sales periods
Customer rating insights to understand user satisfaction

🔹 Features of the Dashboard:
Fully interactive slicers (Month, Brand, Payment Method, Day)
Geo-visualization of sales across major Indian cities
Dynamic KPIs for quick business insights
Clean and user-friendly UI design

📌 What I Learned:
Data cleaning and transformation
Creating effective KPIs and DAX measures
Designing intuitive and insightful dashboards
Turning raw data into actionable insights

This project reflects how data can help businesses understand trends, customer behavior, and improve decision-making.
